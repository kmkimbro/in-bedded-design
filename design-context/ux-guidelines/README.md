# UX guidelines

"When to use which" decision guides, used by the `design-system` skill, the builder and the reviewer.
Start from common practice, map every row to our real component names, and add our own overrides.

Create each guide from `design-context/templates/ux-guideline.md`.

## Planned guides
| File | Chooses between |
|---|---|
| `overlays.md` | Modal, drawer, popover, tooltip, inline expansion |
| `selection.md` | Dropdown, radio buttons, segmented control, checkboxes, toggle, searchable combobox |
| `feedback.md` | Toast, banner, inline message, empty state |
| `navigation.md` | Tabs, accordion, stepper, separate pages |
| `actions-and-menus.md` | Primary / secondary buttons, overflow menus, inline links; menu size, grouping and placement |
| `destructive-actions.md` | Confirm dialog, undo, type-to-confirm |
| `interaction-efficiency.md` | Smart defaults, fewer steps, inline editing, bulk actions |
